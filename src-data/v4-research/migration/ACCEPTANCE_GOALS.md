# Acceptance goals

The upgrade is successful if the app helps with **more of the real run** while becoming no slower to glance at.

High-value outcomes:
- level-up: active + normal passive + special passive choices can be judged
- pre-run: full Class / Subject / Ultimate eligibility can be planned
- fusion: carrier/material visualization remains obvious
- artifact event: candidate comparison takes very few taps and synergy proximity is derived when possible
- phase: timer can automate phase-dependent meta
- recommendation: deterministic fact and community/editorial evidence remain visibly distinct
- data: patch/version/conflict status is retained
- tablet: `지금 뜨면 고르세요` remains the visual center

Do not turn the live screen into a wiki.
