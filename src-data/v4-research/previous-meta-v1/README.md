## 핵심 설계
- 기존 deterministic engine은 유지:
  - 마법/특성
  - 조합 가능성
  - 소비/충돌
  - 슬롯
- 별도 Community Meta Layer:
  - goal / archetype / phase
  - class / subject / ultimate
  - Artifact / Synergy
  - opportunity cost
  - confidence / source / patch
- 추천은 “S티어”보다 **왜 지금 이 선택이 좋은지**를 설명.
- 엔진이 똑똑해져도 Live HUD는 더 복잡해지면 안 됨.
