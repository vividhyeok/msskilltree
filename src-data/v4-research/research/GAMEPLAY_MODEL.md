# Gameplay model for the product

Magic Survival의 실제 선택 리듬을 기준으로 Companion을 생각해야 한다.

1. 레벨업 → 기본 랜덤 3택. 일부 효과로 4택.
2. 필요한 선택이 없으면 Mana Retrieval로 reroll 가능.
3. 액티브는 성장하며 정확한 trait가 fusion 조건이 된다.
4. Lv25/50/75에 fusion 기회가 열린다.
5. fusion은 carrier와 material 역할이 다르며 material 쪽 전용 AF 투자는 fusion 뒤 가치가 사라진다.
6. Class + Subject + 특정 fusion을 맞춘 상태로 Lv100이면 Ultimate.
7. MAX 이후에는 일반 마법 대신 성장강화 phase.
8. 별도로 chest/merchant/obelisk에서 Artifact 의사결정이 발생한다.

그래서 **하나의 거대한 dashboard**보다 사건별 UI가 맞다.

- Level-up glance: NEED NOW + 일반/특수 passive 가치
- Fusion moment: READY + carrier/material
- Artifact event: 3~4 후보 quick compare
- Pre-run: Class/Subject/Ultimate 목표
- Post-MAX: 성장강화 우선도

사용자의 입력량은 게임의 의사결정 수보다 훨씬 적어야 한다.
