# MSSkillTree V4 Research Pack

Codex CLI에 현재 repo와 함께 제공하는 **조사 데이터 + 제품 개선 프롬프트** 패키지.

생성: 2026-09-06  
공식 확인 버전: **v0.992**

## 사용
ZIP을 repo 안의 임시 폴더에 풀고 Codex에:

```text
이 폴더의 CODEX_V4_PROMPT.md와 research/, data/를 읽어.
현재 repo를 먼저 분석한 뒤 이 자료를 보완 자료로 사용해서 업그레이드해줘.
구현 세부는 네가 판단하고, 기존 잘 된 기능은 보존해.
```

라고 주면 됩니다.

- 63 Fusion의 현재 AtWiki 장기생존 editorial tier
- 고영향 Legend Artifact seed
- 고영향 Synergy recipe seed
- 시간대별 Artifact 가치 seed
- current-source conflict / provenance 정책
- 기존 Community Meta v1 snapshot 포함

## 중요한 한계
전체 Artifact/Synergy의 한국어 검증 catalog를 완전히 복제한 팩은 아닙니다.
현재 repo의 existing meta entity 데이터와 병합하도록 만들었습니다.

Wiki의 `tier`는 객관적 사실이 아니므로 반드시 meta/editorial layer에 둡니다.
