# Runtime game data

이 디렉터리는 앱이 실제로 읽는 한국어 런타임 데이터입니다.

## 버전 상태

- 공식 Google Play: **v0.993** 배포 확인 (2026-09-08 확인)
- 이 디렉터리의 상세 수치 기준선: **v0.992**
- 이유: Google Play v0.993 공지는 신규 궁극기/아티팩트/몬스터 및 아티팩트·시너지 개선을 알리지만 상세 변경 수치는 모두 제공하지 않습니다.

따라서 v0.992 한국어 자료에서 확인한 명칭·레시피·효과를 v0.993 값인 것처럼 추정하지 않습니다.

## 한국어 용어 원칙

한국어 게임 자료를 우선하고 일본어/영어를 임의 번역하지 않습니다.

대표 교정:

- 상급마법 → **상급 마법**
- 뇌운 → **먹구름**
- 에너지 공학 → **에너지공학**
- 전쟁 마법 → **전쟁마법**
- 인챈트는 특수 패시브가 아니라 **일반 패시브**
- 타이탄의 힘 → **타이탄의 권능**

## 시너지

`synergies.json`은 한국어 아티팩트 문서에서 이름과 레시피를 확인한 35개만 런타임에 사용합니다.
예전 AtWiki 기반 46개 후보 데이터는 연구 snapshot으로는 남지만 런타임 source-of-truth가 아닙니다.

시너지는 직접 선택하는 항목이 아닙니다. 요구 아티팩트를 모두 보유하면 자동으로 활성화되며 재료는 소모되지 않습니다.
